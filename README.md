# Protocolo de Fármacos HUVM — web estática

- `index.html`: web con buscador de texto, filtro A-Z y filtro de revisión.
- `assets/`: imágenes de las páginas originales para comprobar visualmente el contenido.

## Uso
Abre `index.html` en un navegador.

## Publicación
Es una web estática y puede publicarse en GitHub Pages, Netlify, Cloudflare Pages o un servidor web.

## Criterio documental
El texto se ha extraído del PDF proporcionado. No se corrigen automáticamente dosis, unidades o tablas.
Las discrepancias detectadas se muestran como avisos y la página original queda disponible para comprobación.
